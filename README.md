# BMI Calculator

## Project Overview

The BMI Calculator is a simple and user-friendly application designed to calculate the Body Mass Index (BMI) for users. It allows users to input their weight and height to receive immediate feedback on their BMI and health status.

## Features

- **Weight and Height Input**: Users can enter their weight in kilograms (kg) and height in centimeter(cm).(by default), user can also type height in ft and weight in lb
- **BMI Calculation**: Automatically calculates the BMI based on the provided weight and height.
- **Health Classification**: Provides health categorization based on the calculated BMI (e.g., underweight, normal weight, overweight, Moderate obesity,Severe obesity,Very severe or morbid obesity"
  }).
- **Real-time Feedback**: The application updates the BMI and health suggestions in real-time as users input their weight or height.
- **User-Friendly Interface**: Designed with a clean and simple interface, making it easy for users of all ages to navigate.
- **With a clear button**: User can use this clear button to clear all the button and input
